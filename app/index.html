Collega Cartella di Lavoro

Sistema di gestione documentale offline per fascicoli giudiziari. I dati risiedono esclusivamente nel dispositivo di memoria depositato.

Per utilizzare UX GIUSTIZIA devi collegare una cartella sul tuo computer dove verranno salvati tutti i documenti e i file allegati.

Seleziona la cartella principale del progetto legale. Verrà creata una sottocartella "allegati" automaticamente.
